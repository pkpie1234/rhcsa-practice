# 모두의 창업 프로젝트 — 일반/기술트랙 평가 스킬

본 스킬은 중소벤처기업부 주관 「모두의 창업 프로젝트」 일반/기술트랙(2026년)의 공식 평가 구조를 반영해, 사용자의 창업 아이디어/사업계획/피치덱이 각 라운드에서 통과 가능한지 자가 진단하고 개선 포인트를 도출하기 위한 가이드이다.

**중요:** 정확한 배점/세부 가중치는 운영기관별로 다르며 공개되지 않은 부분이 많다. 본 스킬은 공개된 공고문·기사·해설 자료에서 확인된 평가 항목을 기반으로 한 **참고용 휴리스틱**이며, 공식 점수가 아니다.

---

## 1. 트랙·전체 구조 요약

- 주관: 중소벤처기업부 / 운영: 100여 개 창업보육기관·선배 창업가 멘토단(약 500명)
- 일반/기술트랙: 4,000명 선발 (전체 5,000명 중 1,000명은 로컬트랙)
- 단계: **아이디어 심사 → 1R(지역예선) → 2R(지역오디션) → 3R(권역오디션) → 4R(전국오디션·결승)**
- 평가 철학: 서류보다 **발표·멘토 평가 비중**이 크다. 책임멘토가 모든 라운드에 관여한다.

| 단계 | 성격 | 주요 지원 |
|---|---|---|
| 아이디어 심사 | 책임멘토 종합평가 | 활동자금 200만원 + AI솔루션(월100만원·2개월) + 1:1 책임멘토링 |
| 1R 지역예선 | 관찰식 + 서면평가 | 시제품 제작비 최대 1,000만원 + 기술멘토링 |
| 2R 지역오디션 | 멘토링·발표·자금활용 종합 | 시제품 제작비 최대 1,000만원 + 선배멘토링 |
| 3R 권역오디션 | 시제품·사업계획 평가 | 차년도 사업화자금 최대 1억원 |
| 4R 전국오디션(결승) | 종합 발표 평가 | 우승자 상금 5억 + 투자 5억 = 10억원 이상 |

## 2. 평가 지표 (라운드 공통 8축)

각 라운드 가중치는 다르지만, 공고/기사/해설을 토대로 도출한 핵심 평가축은 다음 8가지다.

| 코드 | 평가축 | 핵심 질문 | 만점 |
|---|---|---|---|
| D | **차별성 (Differentiation)** | 기존 솔루션 대비 무엇이 다른가? 모방 장벽은? | 10 |
| E | **효과성 (Effectiveness)** | 정의한 문제를 실제로 얼마나 해결하는가? | 10 |
| I | **혁신성 (Innovation)** | 기술/모델/접근의 신규성·기여도 | 10 |
| F | **실현가능성 (Feasibility)** | 기술적·자원적 실행 가능 여부, 12개월 내 검증 가능성 | 10 |
| M | **시장성 (Market Potential)** | TAM/SAM/SOM, 진입 타이밍, 고객 니즈 검증 | 10 |
| S | **성장가능성 (Scalability)** | 확장성, 글로벌·다 segment 확장 경로 | 10 |
| T | **창업가/팀 역량 (Team)** | 도메인 전문성, 실행력, 팀 구성 | 10 |
| B | **사업모델 (Business Model)** | 수익구조, 단위경제, 가격·채널 설계 | 10 |

총점 80점 환산.

## 4. 라운드별 체크리스트

### 4.1 아이디어 심사 — "도전신청서" 기준

책임멘토가 신청서 + 이미지(5장 이내) + 숏폼(30~60초) 기반으로 평가.

- [ ] **문제 정의**: 누가, 언제, 어떤 상황에서 겪는 문제인지 1문단 안에 들어오는가
- [ ] **차별성**: "기존엔 X로 해결했지만 우리는 Y라서 다르다" 한 줄이 있는가
- [ ] **효과성**: 정성·정량 효과(시간/비용/만족도) 중 하나라도 수치 가설이 있는가
- [ ] **숏폼**: 30~60초 안에 문제·해법·차별점이 모두 들어가는가
- [ ] **이미지**: 5장 안에 와이어프레임/사용 시나리오/팀이 보이는가
- [ ] **AI 솔루션 활용 계획**: 지급되는 AI 도구를 어떤 검증에 쓸지 명시했는가

### 4.2 1R 지역예선 — "참여 과정" 평가

관찰식 + 서면. 책임멘토 추천 + 멘토링 보고서가 핵심.

- [ ] **멘토링 출석률** 90% 이상
- [ ] **멘토링 보고서**: 매 회차 액션아이템·결과·다음 가설이 적혔는가
- [ ] **시제품/MVP 진척**: 1,000만원 시제품 제작비 집행 계획이 명확한가
- [ ] **기술 검증 로그**: 핵심 가정 1개 이상을 실제 사용자/데이터로 검증했는가
- [ ] **피드백 반영**: 멘토 코멘트별 변경사항 추적표 보유

### 4.3 2R 지역오디션 — 발표 + 종합

- [ ] **발표 자료(8~12장)**: 문제 → 솔루션 → 시장 → BM → 트랙션 → 팀 → 자금계획 흐름
- [ ] **트랙션 슬라이드**: 1R 자금으로 만든 결과물 캡처/숫자 1개 이상
- [ ] **사업화자금 활용 내역**: 사용처와 그것이 만들어낸 학습·결과 매핑
- [ ] **2분 / 5분 / 10분 피치 3종** 준비
- [ ] **예상 Q&A 10개** (시장 사이즈, 경쟁사, 기술 차별점, 수익화)

### 4.4 3R 권역오디션 — 시제품 + 사업계획

- [ ] **시제품 데모**: 5분 내 핵심가치를 라이브로 보여줄 수 있는가
- [ ] **사업계획서 v2**: 단위경제(LTV/CAC, 매출원가) 1페이지 포함
- [ ] **시장 진입 계획**: 6/12/24개월 마일스톤
- [ ] **기술 IP 전략**: 특허/노하우/데이터 자산 정리
- [ ] **차년도 1억원 활용 로드맵**: 채용·R&D·마케팅 분배

### 4.5 4R 전국오디션 — 결승

- [ ] **8분 결승 피치** + **5분 Q&A** 시뮬레이션 ≥ 5회
- [ ] **투자유치 IR 자료** (5억 매칭투자 가정 시 사용 계획서 포함)
- [ ] **지표 트리거**: 결승 시점까지의 MAU/매출/계약 등 1지표 시각화
- [ ] **글로벌·확장 시나리오** 1슬라이드
- [ ] **리스크 & 대응**: 규제/경쟁/기술 리스크별 대응 계획

## 5. 사용 방법 (Claude가 호출되었을 때 따라야 할 절차)

사용자가 본 스킬을 트리거(예: "내 아이디어 모두의 창업 기준으로 평가해줘", "사업계획서 점검해줘")한 경우 다음 순서로 진행한다.

### Step 1. 입력 수집
다음을 사용자에게 물어보고, 누락 시 가장 임팩트 큰 항목부터 보완 요청.
1. 도전신청서 / 사업계획서 / 피치덱 (텍스트, 파일 경로, 또는 요약)
2. 현재 목표 라운드 (아이디어 / 1R / 2R / 3R / 4R)
3. 트랙(일반 또는 기술) 및 도메인
4. 현재까지의 트랙션(있다면)

### Step 2. 평가 실행
- §2의 8축 × §3의 라운드별 가중치로 점수 산정
- 각 축에 대해 0~10점 + 한 줄 근거(`reason`) + 한 줄 개선 권고(`fix`)
- 가중 평균(100점 환산) 산출

### Step 3. 출력 포맷 (Markdown)

```markdown
## 평가 요약 — [목표 라운드]
- **종합 점수**: 78.4 / 100  ▢▢▢▢▢▢▢▢░░
- **추천 등급**: A / B / C / D (B 이상이면 라운드 통과 기대선)
- **3대 강점**: …
- **3대 보완 과제**: …

### 축별 평가
| 축 | 점수 | 가중치 | 근거 | 개선 권고 |
|---|---:|---:|---|---|
| 차별성 | 7/10 | 15% | … | … |
| … | | | | |

### 라운드 체크리스트 결과
- [x] 문제 정의 / [ ] 차별성 한 줄 …

### 우선순위 액션 3가지
1. …
2. …
3. …
```

### Step 4. 후속 제안
- 다음 라운드로 가려면 무엇을 어떤 순서로 만들어야 하는지 1·2·4주 단위 로드맵
- 멘토링·발표 자료 템플릿 요청 시 §6 참조

## 6. 평가 루브릭 (각 축별 0/4/7/10점 기준)

각 축에 대해 다음 4개 단계 중 가장 가까운 점수를 부여한다.

### 차별성 (D)
- 0: 기존 제품/서비스와 구분되는 점이 명확하지 않음
- 4: 차이점은 있으나 모방 가능 / 표면적
- 7: 명확한 차별점 + 경쟁 분석 존재
- 10: 데이터/IP/네트워크 효과로 모방 장벽 형성

### 효과성 (E)
- 0: 효과 주장만 있고 근거 없음
- 4: 정성적 효과 추정
- 7: 사용자 인터뷰/베타 데이터로 효과 입증 시도
- 10: 정량 지표(시간↓X%, 비용↓Y%, 전환률↑Z%p)

### 혁신성 (I)
- 0: 기존 카피
- 4: 점진적 개선
- 7: 카테고리 내 독자적 접근
- 10: 새로운 카테고리/패러다임 제시

### 실현가능성 (F)
- 0: 기술·자원 모두 부재
- 4: 기술 가능성만 있고 일정·자원 미정
- 7: 6~12개월 내 MVP 가능
- 10: 핵심기술 검증 완료, 시제품 보유

### 시장성 (M)
- 0: 시장 정의 없음
- 4: TAM만 추정
- 7: TAM/SAM/SOM + 1차 고객군 정의
- 10: 시장 검증 + 진입 타이밍 근거 + 결제의향 데이터

### 성장가능성 (S)
- 0: 한 지역/세그먼트에 한정
- 4: 인접 시장 확장 아이디어
- 7: 다지역/다세그먼트 확장 로드맵
- 10: 글로벌/플랫폼화 + 단위경제 양호

### 팀 역량 (T)
- 0: 1인 + 도메인 비전문
- 4: 1인 + 도메인 전문 또는 2인 보완
- 7: 도메인+기술+사업 3축 중 2축 충족
- 10: 3축 모두 충족, 과거 실행 트랙 레코드 보유

### 사업모델 (B)
- 0: 수익모델 없음
- 4: 수익모델 가설만 존재
- 7: 단위경제(가격·CAC·LTV) 1차 수치
- 10: 단위경제 검증 + 채널 전략 + 가격 실험 결과

## 7. 흔한 탈락 사유 (반드시 회피)

1. 차별성 슬라이드에 경쟁사가 없음 → 즉시 탈락 사유
2. "TAM 100조" 류의 근거 없는 큰 숫자 → 신뢰도 추락
3. 시제품 영상이 없음 (1R 이후) → 실현가능성 0점
4. 멘토링 출석/보고서 미흡 → 1R 관찰평가에서 컷오프
5. 사업화자금 사용 내역이 막연함 → 2R 종합평가 감점
6. 8분 발표에 데모가 없음 → 4R 결승 치명적
7. Q&A 답변이 자료보다 길고 우회적 → 평가위원 신뢰 하락
