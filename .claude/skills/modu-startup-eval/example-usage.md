# 사용 예시 — modu-startup-eval

## 예시 1. 아이디어 심사 단계 점검

**사용자**: "내 아이디어 모두의 창업 아이디어 심사 기준으로 평가해줘. 아이디어: 시각장애인을 위한 AI 메뉴판 음성안내 앱."

**스킬 동작**:
1. SKILL.md §5 Step 1로 누락 정보(타깃 시장 규모, 팀 구성, 트랙션) 질문
2. 답변을 받으면 §3 가중치(D 25, E 20, I 20, F 15, M 10, S 5, T 5)로 점수화
3. §6 루브릭으로 각 축 0/4/7/10 부여
4. §5 Step 3 포맷으로 결과 출력

## 예시 2. 2R 발표자료 사전 점검

**사용자**: "다음 주 2R 오디션인데, 슬라이드 보고 점수 매겨줘. (deck.pdf 첨부)"

**스킬 동작**:
1. PDF에서 텍스트 추출
2. §4.3 2R 체크리스트 적용
3. 발표력·자금 활용 등 관찰 항목은 추가 질문으로 보강
4. 우선순위 액션 3가지 + Q&A 예상 10개 생성
