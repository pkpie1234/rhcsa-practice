# 모두의 창업 — 일반/기술트랙 평가 스킬

중소벤처기업부 「모두의 창업 프로젝트」 일반/기술트랙(2026)의 공개 정보를 토대로 만든 Claude Code 스킬이다. 도전신청서·사업계획서·피치덱을 라운드별 평가지표로 자가 진단할 수 있도록 돕는다.

## 설치된 스킬

- `.claude/skills/modu-startup-eval/SKILL.md` — 메인 스킬 (평가 절차·루브릭·체크리스트)
- `.claude/skills/modu-startup-eval/rubric.json` — 라운드별 가중치(머신리더블)
- `.claude/skills/modu-startup-eval/example-usage.md` — 호출 예시

## 사용

Claude Code 세션에서 다음과 같이 자연어로 호출한다.

```
내 사업계획서 모두의 창업 2R 기준으로 평가해줘
```

또는 명시적으로:

```
/modu-startup-eval
```

## 평가 8축

차별성(D) · 효과성(E) · 혁신성(I) · 실현가능성(F) · 시장성(M) · 성장가능성(S) · 팀역량(T) · 사업모델(B)

## 라운드 구조 (일반/기술트랙)

아이디어 심사 → 1R 지역예선 → 2R 지역오디션 → 3R 권역오디션 → 4R 전국오디션(결승)

세부 배점·체크리스트는 `SKILL.md` 참고.

## 면책

가중치는 공개된 공고문·기사·해설을 기반으로 한 **추정치**이며 운영기관별 실제 배점과 다를 수 있다. 공식 평가가 아닌 자가 점검용으로만 사용한다.
